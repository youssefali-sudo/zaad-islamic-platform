# زاد | ZAAD

A multilingual Islamic learning and daily-practice platform.

## Technology
- HTML, CSS, JavaScript and TypeScript: responsive web application.
- C++: portable habit/streak calculation core (WebAssembly-ready).
- Python: optional FastAPI content service.
- Go: lightweight health gateway.
- Rust: content-pack validation CLI.
- Java: reference/content audit CLI.
- C#: local progress backup utility.
- SQL: PostgreSQL schema.
- Bash: development and validation scripts.

## Run the web app
Open `web/index.html` in a browser, or serve the repository root with any static web server. The web app stores personal progress locally in the browser; no account is required.

## Optional services and tools
See each folder README. The static web app works independently. Quran text is requested from AlQuran Cloud when online; verify religious references against trusted sources before publishing.

## Principles
- No shame-based language in habit support.
- Progress is private and stored locally by default.
- Quran and hadith references must be explicit; never fabricate sources.
- Accessibility, responsive layout, Arabic RTL and English LTR.
